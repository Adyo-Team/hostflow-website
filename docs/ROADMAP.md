# HostFlow — roadmap

Le repository et [STATUS.md](STATUS.md) décrivent l'existant. Les étapes suivantes sont des objectifs, sans dates annoncées.

- **v0.6 — Operations / Tasks ✅** : socle livré ; limites de validation documentées dans STATUS.
- **v0.7 — Dashboard opérationnel**.
- **v0.8 — Owners / propriétaires**.
- **v0.9 — Guests / CRM voyageurs**.
- **v1.0 — Integrations : Airbnb / Booking / Vrbo / iCal**.
- **Ensuite** : automatisations, messagerie, finances/reporting et assistant IA.

Chaque évolution réutilise le modèle Organization, les permissions et le design system existants. Une entrée dans cette roadmap ne signifie pas que la fonctionnalité ou l'intégration est déjà disponible.
